# CCTALK作业导出 Chrome 扩展

一键导出 CCTALK 作业解析为 PDF 文件。

## 功能特点

- 一键导出：在 CCTALK 作业报告页面点击扩展图标，点击"导出解析 PDF"按钮即可
- 自动获取：自动拦截页面数据，无需手动操作开发者工具
- 完整解析：导出题干、选项、正确答案（绿色高亮）和详细解析
- 图片支持：自动下载并嵌入题目中的图片
- 本地处理：所有数据处理均在本地完成，保护隐私

## 安装方法

### 方法一：开发者模式加载（推荐）

1. 下载或克隆此项目到本地
2. 打开 Chrome 浏览器，访问 `chrome://extensions/`
3. 开启右上角的"开发者模式"
4. 点击"加载已解压的扩展程序"
5. 选择 `chrome-plugin` 文件夹
6. 扩展安装完成！

### 方法二：打包安装（准备中）

待发布到 Chrome 应用商店后，可直接搜索安装。

## 使用方法

1. 打开 CCTALK 作业报告页面（必须是作业查看报告页面）
2. 点击浏览器工具栏中的扩展图标
3. 如果页面包含作业数据，"导出解析 PDF"按钮将可用
4. 点击按钮，等待几秒钟，PDF 将自动下载

## 常见问题

### 为什么按钮显示"未找到作业数据"？

- 请确保您在 CCTALK 的**作业查看报告**页面
- 刷新页面后重试
- 打开浏览器控制台（F12）查看是否有错误信息

### PDF 下载很慢怎么办？

- 作业题目较多时（如100题）生成时间会较长
- 图片较多时下载需要更多时间
- 请耐心等待，不要重复点击

### 导出的 PDF 字体显示不正常？

- 扩展使用内置字体，应该能正常显示中文
- 如有问题，请确保使用最新版本的 Chrome/Edge 浏览器

## 技术栈

## 隐私说明

- 不会向任何外部服务器发送您的作业数据
- 不收集任何用户信息
