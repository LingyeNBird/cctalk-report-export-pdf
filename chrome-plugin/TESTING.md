# 测试指南

## 安装测试

1. 打开 Chrome，访问 `chrome://extensions/`
2. 启用"开发者模式"
3. 点击"加载已解压的扩展程序"
4. 选择 `chrome-plugin` 目录
5. 确认扩展成功加载，无错误

## 功能测试

### 测试场景 1：正常导出

1. 访问 CCTALK 作业报告页面
2. 点击扩展图标
3. 验证：
   - 状态显示"准备就绪"
   - 导出按钮可用
4. 点击"导出解析 PDF"
5. 验证：
   - 状态显示"正在生成PDF..."
   - 几秒后显示"PDF已下载"
   - 下载文件出现在下载目录
6. 打开 PDF 验证：
   - 标题正确
   - 题目编号正确
   - 选项格式正确
   - 正确答案为绿色 (#1B8A3B)
   - 解析有边框

### 测试场景 2：无数据页面

1. 访问非 CCTALK 页面（如 https://www.google.com）
2. 点击扩展图标
3. 验证：
   - 状态显示"未找到作业数据"
   - 导出按钮禁用

### 测试场景 3：大文件测试

1. 访问包含100+题的作业报告
2. 点击导出
3. 验证：
   - 生成时间合理（< 30秒）
   - PDF 文件完整
   - 所有题目都包含在内

### 测试场景 4：带图片的题目

1. 访问包含图片的作业
2. 导出 PDF
3. 打开 PDF 验证：
   - 图片正确显示
   - 图片尺寸合适（不超出页面宽度）

### 测试场景 5：材料题

1. 访问包含材料题的作业（有子题目）
2. 导出 PDF
3. 打开 PDF 验证：
   - 材料题显示一次"材料："
   - 子题目正确编号
   - 格式清晰

## 控制台检查

按 F12 打开开发者工具，查看 Console 标签页，应该看到：

```
[CCTALK Export] Content script loaded
[CCTALK Export] Captured report data: {...}
[CCTALK Export] Download started: <id>
```

没有红色错误信息。
